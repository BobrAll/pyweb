# Лицензии

Проект использует **раздельное лицензирование** для разных типов контента.

## Код

Исходный код проекта (скрипты сборки, конфигурация CI/CD, вспомогательные
скрипты) лицензируется на условиях **MIT License**.

Полный текст: [LICENSE](https://github.com/BobrAll/pyweb/blob/main/LICENSE)

## Контент

Тексты, страницы документации, изображения, графики и таблицы
лицензируются на условиях **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

Полный текст: [LICENSE-CONTENT](https://github.com/BobrAll/pyweb/blob/main/LICENSE-CONTENT)

Краткое описание: https://creativecommons.org/licenses/by/4.0/

## Данные

Исходные данные экспериментов (если публикуются) лицензируются отдельно
и будут указаны на странице соответствующего эксперимента.

## Почему раздельно

- **Код** распространяется по MIT — это разрешительная лицензия, удобная
  для переиспользования инструментов.
- **Контент** распространяется по CC BY 4.0 — это соответствует практике
  научных публикаций и требованию атрибуции.
- **Данные** требуют отдельного решения, поскольку могут иметь ограничения
  на распространение (персональные данные, лицензии источников).

Раздельное лицензирование — требование принципов **FAIR**
(Findable, Accessible, Interoperable, Reusable), см. задание Т5.
