# P3. Воспроизводимый конвейер «данные → результат → сайт»

## Реализация

Скрипт `scripts/run_experiment.py` читает `data/experiment.csv`, выполняет подгонку
модели затухания $A e^{-t/\tau}$, строит графики и записывает результаты в
`docs/_data/`. При сборке значения подставляются в страницу «Эксперименты»
через `mkdocs-macros`. Вызов скрипта встроен в `Makefile`, `run_local.sh`
и шаг `Run experiment pipeline` обоих deploy-workflow.

Результаты кэшируются в `.build/experiment/`: манифест содержит хеши данных и скрипта;
при совпадении пересчёт пропускается.

## Проверка

Все команды выполняются из корня репозитория.

### 1. Конвейер и кэш

```bash
make pipeline
```

Первый запуск — пересчёт:

```text
cache miss: recomputed in 0.15 s
```

Повторный запуск без изменения данных:

```text
cache hit: results loaded in 0.002 s
```

Разница — примерно два порядка. Замер сохраняется в `docs/_data/pipeline.json`
и выводится на странице «Эксперименты» в таблице «Кэширование конвейера».

### 2. Сборка и сверка страницы

```bash
make build
```

Открыть `site/experiments/index.html` и сверить:

| Элемент | Ожидаемое значение |
|---|---|
| Коммит | хеш текущего `HEAD` |
| Версия набора данных | `0bb0b4126578` |
| Параметры модели | $A = 2.4306$, $\tau = 4.0939$, $R^2 = 0.9957$ |
| Графики | точки из CSV + линия модели |
| Таблица кэширования | время пересчёта, время из кэша, процент |

### 3. Обновление сайта при изменении данных

Изменить значение в `data/experiment.csv`, например `0.0,2.5091` → `0.0,3.1000`,
затем:

```bash
git commit -am "Changed experiment data"
git push
```

Workflow `Deploy MkDocs` выполняет `scripts/run_experiment.py` (в логе —
`cache miss: recomputed in ...`), затем `mkdocs build --strict` и публикацию.

После завершения workflow проверить на странице «Эксперименты»:

| Признак | Раздел страницы |
|---|---|
| Изменившаяся версия данных (SHA-256) | Метка версии сборки |
| Новые значения амплитуд | Измеренные данные |
| Новые $A$, $\tau$ | Результаты подгонки |
| Обновлённые кривые | статический и интерактивный графики |
| Зелёная подсветка таблиц в течение минуты после пересчёта | Результаты подгонки, Измеренные данные |

### 4. Контроль версии данных

```bash
shasum -a 256 data/experiment.csv
```

Первые 12 символов хеша совпадают со значением «Версия набора данных»
на странице (в Linux — `sha256sum`).
