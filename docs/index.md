# Публикация результатов исследований

## О проекте

Сайт публикует результаты экспериментов, графики и таблицы,
построенные автоматически из исходных данных.

## Стек

- **Генератор**: MkDocs + тема Material, Sphinx
- **CI/CD**: GitHub/GitVerse Actions
- **Хостинг**: GitHub/GitVerse Pages + Helios ИТМО
